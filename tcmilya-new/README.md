# ТРЦ «Миля»: новый сайт

Статический сайт торгово-развлекательного центра «Миля» (Москва, ул. Генерала Кузнецова, 22, метро Жулебино).
Чистый HTML, CSS и JavaScript без фреймворков и сборщиков. Из внешнего грузятся только шрифты Google Fonts (Unbounded и Onest), для них настроены fallback-шрифты с подогнанными метриками.

## Как запустить

**С диска.** Откройте `index.html` двойным кликом. Всё работает и по `file://`: скрипты подключены обычными `<script>`, данные лежат в JS, а не в JSON.

**Локальный сервер** (так ближе к продакшену):

```bash
cd tcmilya-new
npx http-server -p 8080 -c-1     # или: python3 -m http.server 8080
# открыть http://localhost:8080/
```

**Netlify.**
- Из репозитория: в корне лежит `netlify.toml` с `publish = "tcmilya-new"`, сборочная команда не нужна.
- Вручную: перетащите папку `tcmilya-new` в Netlify Drop. Файлы `_headers` (кэш, заголовки безопасности) и `_redirects` подхватятся сами, `404.html` отдается на неизвестные адреса.

## Где менять контент

Почти всё в одном файле: **`js/data.js`**.

| Что | Где в `data.js` | Примечание |
| --- | --- | --- |
| Магазины, кафе, услуги | `TENANTS` | `id`, `name`, `cat`, `floor`, `unit`, `hours`, `phone`, `site`, `desc`, `tags`. Поле `logo` (путь к картинке) заменит словесный знак на логотип. `stub: true` отмечает заглушку. |
| Категории | `CATEGORIES` | `section` определяет раздел сайта, `icon` берется из `tools/partials/sprite.svg`. |
| Новости и акции | `NEWS` | `type`: `promo`, `event`, `news`, `cinema`. `image`: путь к фото, пока `null` (рисуется SVG-обложка). Отдельная страница строится автоматически по `id`. |
| Фильмы | `FILMS` | `poster` для постера. Сеансы генерируются функцией `Milya.sessions()` в `js/core.js`. |
| Схема этажей | `FLOORS` | Два ряда помещений на этаж (`top`, `bottom`), в каждом ряду сумма ширин 960. Id помещения совпадает с id арендатора. |
| Режим работы | `HOURS` | По нему считается статус «Открыто до 22:00» (московское время, обновляется раз в 30 секунд). |
| Ссылка на билеты | `KINOMAX_URL` | Используется всеми кнопками «Купить билет» и сеансами. |
| Маршрут | `ROUTE_URL`, `MAP_URL` | Яндекс Карты. |

**Шапка, подвал, иконки, общий `<head>`** лежат в `tools/partials/`. После правки запустите:

```bash
node tools/build.mjs
```

Скрипт вставит общие блоки во все страницы между маркерами `<!-- layout:* -->`, встроит `css/critical.css`, проставит активный пункт меню и пересоберет `sitemap.xml`. Зависимостей нет, нужен Node 18+. Сами страницы остаются обычным HTML, их можно править руками.

**Картинки.** Все обложки сейчас генерируются как SVG (функция `art()` в `core.js`). Чтобы поставить фото, положите файл в `assets/img/...` и укажите путь в `image` (новости), `poster` (фильмы) или `logo` (арендаторы). Изображения подключаются с `loading="lazy"`.

## Что проверено

- Ширина 390 px и 1440 px на всех 13 страницах: без горизонтального скролла, в каждой странице ровно один `<h1>`.
- Светлая и темная тема (`prefers-color-scheme`), axe-core WCAG 2 A/AA: нарушений нет.
- Lighthouse (мобильный профиль): Performance 97-100, Accessibility 100, Best Practices 100, SEO 100 на всех страницах.
- Все внутренние ссылки отвечают 200, ошибок в консоли нет, сайт работает с диска (`file://`).
- Функции: быстрый поиск с подсказками и клавиатурой, фильтры каталога и синхронизация с URL (`?q=`, `?cat=`, `?floor=`, `?shop=`), диалог магазина, бургер-меню (Esc, фокус не уходит), переключатель дней в кино (стрелки), поиск на схеме с подсветкой и переключением этажа, валидация формы аренды, cookie-баннер с запоминанием, `prefers-reduced-motion`.
